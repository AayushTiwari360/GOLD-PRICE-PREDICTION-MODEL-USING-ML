# GOLD-PRICE-PREDICTION-MODEL-USING-ML
Machine Learning Model for Gold Price Prediction using R² Score A machine learning model for Gold Price Prediction leverages historical price data and relevant financial indicators to forecast future gold prices. The R² score (coefficient of determination) is a key metric for evaluating how well the model explains the variability of the gold price.
